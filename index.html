Basics refresher

The simple stuff, defined

Every "obvious" word the lectures assume you know, in one or two lines each. Look things up here whenever a word feels fuzzy.

Data and variables

Observation
One row of data: one person, firm, country or store at one time.
Variable
One column of data, something measured for each observation (wage, age).
Population vs sample
Population = everyone you care about. Sample = the part you actually observed. We use the sample to learn about the population.
Parameter
A fixed but unknown number describing the population, like the true mean μ or true slope β.
Dummy (indicator) variable
A variable that is 1 or 0: treated or not, female or not, NJ or PA.
Continuous vs discrete
Continuous can take any value in a range (height). Discrete takes separate values (number of kids).
Cross-section / time series / panel
Many units at one time / one unit over many times / many units over many times.
Observational data
Data you just collected from the world, with no experiment. Treatment wasn't randomised, so causality is hard.

Describing data

Mean (average), x̄
Add everything up, divide by how many. x̄ = Σxᵢ / n.
Median
The middle value when sorted. Not pulled around by extreme values like the mean is.
Mode
The most common value, or a peak in a distribution. "Unimodal" = one peak.
Variance
Average squared distance from the mean: how spread out the data are. Var(x) = Σ(xᵢ − x̄)² / n (or n − 1 for the sample version).
Standard deviation (SD, σ)
Square root of the variance. Spread in the original units. "0.48 SD" = 0.48 of a standard deviation.
Covariance
Do two variables move together? Cov(x,y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / n. Positive = up together, negative = opposite. Units are awkward.
Correlation
Covariance rescaled to lie between −1 and 1. ±1 = perfect straight line; 0 = no linear relationship.
Percentile
The value below which that % of data falls. 75th percentile: 75 % of values are lower.
Outlier
A point far from the rest. Can drag means and regression lines around.
Demeaning
Subtracting the mean from a variable, so the new version averages zero: x̃ᵢ = xᵢ − x̄.

Probability

Random variable
A quantity whose value depends on chance, like a die roll or the wage of a randomly picked person.
Distribution
The full list of possible values and how likely each one is.
PDF (density)
Probability density function: the curve showing where values are likely. Area under it = probability.
CDF
Cumulative distribution function: F(x) = P(X ≤ x), the probability of being at most x. Goes from 0 up to 1.
Expectation, E[X]
The long-run average value of a random variable, its "population mean".
Conditional expectation, E[Y | X]
The average of Y among those with a given X. E[wage | educ = 12] = average wage of people with 12 years of school.
Independence (⫫)
Knowing one variable tells you nothing about the other.
i.i.d.
Independent and identically distributed: each observation is a separate draw from the same distribution.
Normal distribution, N(μ, σ²)
The bell curve. Mean μ, variance σ². About 95 % of values lie within ±1.96 SD of the mean.
Bernoulli / Binomial
Bernoulli = one yes/no trial with probability p. Binomial = number of successes in n such trials.
Poisson
Distribution for counts (0, 1, 2…) of events.
Exponential
Distribution for waiting times between random events.
t, χ², F distributions
Distributions of test statistics. t ≈ normal but fatter tails for small samples; χ² and F are for tests of several things at once.

The two big theorems

Law of Large Numbers (LLN)
With more and more data, the sample mean gets closer and closer to the true mean.
Central Limit Theorem (CLT)
With enough independent observations from a distribution with a finite variance, the sample mean is approximately normally distributed, even if the data themselves aren't. "Enough" depends on how skewed the data are. This is why normal-based tests work so often.

Estimation

Estimator vs estimate
Estimator = the recipe (e.g. "take the sample mean"). Estimate = the number you get from your particular sample. The hat (β̂) marks both.
Sampling variation
A different sample would give a different estimate. The estimator is itself a random variable.
Bias
E[β̂] − β: how far off the estimator is on average. Unbiased = right on average.
Standard error (SE)
The standard deviation of an estimator across hypothetical repeated samples: how much it would wobble. Smaller = more precise.
SD vs SE
SD describes the spread of the data. SE describes the uncertainty of an estimate. SE shrinks as n grows (roughly SD/√n for a mean); SD doesn't.
Consistent
The estimator converges to the true value as the sample size grows.
Efficient
Has the smallest variance among a class of estimators.
Asymptotic
"In very large samples." Asymptotic results are approximations for big n.
Identification
Whether the data could in principle pin down the parameter, even with infinite data. Comes before estimation.
Residual vs error
Error ε = true unobserved deviation from the true line. Residual ε̂ = observed deviation from your fitted line.
Fitted value, ŷ
The value the model predicts for an observation.
Intercept / slope
Intercept: predicted y when all x's are 0. Slope: change in y per one-unit change in x.
Control variable
A variable added to a regression so comparisons are made between people similar in that variable.
Ceteris paribus
Latin for "other things equal": the effect of x holding everything else fixed.

Testing

Hypothesis
A claim about a parameter you want to check, e.g. "β = 0".
Null hypothesis (H₀)
The default "nothing going on" claim you test against (usually: no effect).
Alternative (H₁)
What you accept if you reject H₀ (usually: there is an effect).
Test statistic
A number computed from data to judge H₀, like t = β̂ / SE.
Significance level (α)
The cut-off for rejecting, usually 5 %. "Significant at 5 %" = p < 0.05.
p-value
If the model and H₀ were true, the chance of a test statistic at least as extreme as yours. Small = data look incompatible with H₀. It is not the probability that H₀ is true.
Type I / Type II error
Type I: rejecting a true H₀ (false alarm). Type II: not rejecting a false H₀ (missed effect).
Power
Chance of correctly rejecting a false H₀. More data = more power.
Confidence interval
A range built by a method that captures the true value in, say, 95 % of repeated samples. Roughly estimate ± 2 × SE.
Degrees of freedom
Number of observations minus number of estimated parameters (n − p). Used to pick the right t or F distribution.
Stars (*, **, ***)
Shorthand in tables for significance at 10 %, 5 %, 1 %. Your lecturer warns against reading too much into them.

Math tools

Σ (sum)
Σᵢ xᵢ = x₁ + x₂ + … + xₙ.
Π (product)
Πᵢ xᵢ = x₁ · x₂ · … · xₙ.
log (natural log)
The inverse of eˣ. Key property: log(a·b) = log a + log b. A small change in log x ≈ the percentage change in x (Δlog x = 0.05 ≈ 5 %).
exp, e
e ≈ 2.718. exp(x) = eˣ. exp(log x) = x.
Derivative
The slope of a function at a point: how fast it changes. At a maximum or minimum the derivative is 0. That's why we "set the derivative to zero" (first-order condition, FOC).
Second derivative
How fast the slope changes, i.e. the curvature. Negative at a maximum.
argmax
"The value of θ that makes this biggest." The max is the height; the argmax is where it happens.
Limit (lim x↓c)
The value a function approaches as x gets closer and closer to c. ↓ = from above, ↑ = from below.
Indicator 1{…}
Equals 1 if the condition is true, 0 otherwise.
Matrix
A table of numbers. X in regression has one row per observation and one column per variable.
Transpose, Xᵀ
Flip a matrix so rows become columns.
Inverse, A⁻¹
The matrix version of dividing: A⁻¹A = I. Not every matrix has one (e.g. perfectly collinear X).
Identity matrix, I
1s on the diagonal, 0s elsewhere. The matrix version of the number 1.
Orthogonal (⊥)
Perpendicular. For data vectors: their products sum to zero, i.e. they're uncorrelated in that sense.

Regression basics

Regression draws the line that best fits a cloud of points, then tells you how steep that line is and how sure you can be about it.

About 35 min in Full modeAbout 10 min in Gist mode

Gist mode is on: deeper sections are hidden. Switch to Full at the top when you're ready for more.

Quick reminders
Variance
How spread out something is: the average squared distance from its mean.
Covariance
Whether two variables move together (positive) or in opposite directions (negative).
Residual
Actual y minus the y your line predicts: the leftover mistake for one data point.
Standard error
How much an estimate would wobble if you redid the study with a new sample.
log
Natural logarithm. A change of 0.05 in log y ≈ a 5 % change in y.

If you remember only 3 things

  1. OLS picks the line that makes the squared mistakes as small as possible. The slope β̂ tells you how much Y changes when X goes up by 1, holding the other X's fixed.
  2. A regression shows association, not causation. If you leave out something that affects Y and is linked to X (like "ability"), your slope is biased.
  3. p-values and confidence intervals assume your model is right. They measure uncertainty from sampling, not whether the model is true.

What is regression for?

Two very different jobs:

"What will happen?""Why did it happen?"

The model, in words

y = β₀ + β₁x₁ + β₂x₂ + … + βpxp + ε
y
outcome (also "dependent variable")
x₁ … xp
things that might explain y ("regressors", "features")
β₀
intercept: predicted y when all x's are 0
β₁
slope: change in y when x₁ goes up by 1 and the other x's stay the same
ε
error: everything else we didn't measure

In matrix form the same thing is written y = Xβ + ε. X is just a table: one row per person, one column per variable, plus a column of 1s for the intercept.

Think of it like

A map. A map is useful because it leaves things out. Your lecturer's line: "The purpose of the model is to be useful. It is not to be correct." It should be right about the part you care about.

What the line is aiming at: the conditional expectation

E[Y | X = x] is the average of Y among everyone with that value of x: the average wage of people with 12 years of school, of people with 13 years, and so on. Plot those averages and you get the conditional expectation function (CEF).

  • If the CEF is a straight line, regression recovers it exactly (in large samples).
  • If it's curved, OLS gives the best straight-line approximation to it. That's still useful, but check with a plot.
  • The error ε is "Y minus its conditional average". The assumption E[ε | X] = 0 says the line gets the averages right for every x.

This is a statement about averages among people who differ in X. Whether changing someone's X would change their Y is a different, causal question (lecture 4).

Least squares: how the line is chosen

β̂ = (XᵀX)⁻¹ Xᵀy
Xᵀy
how much each x moves together with y
(XᵀX)⁻¹
divides by how much the x's vary (and overlap with each other)

With one x this collapses to the formula you can remember: β̂₁ = Cov(x, y) / Var(x). You'll see this shape again in IV.

Geometrydeeper
Fitting OLS = dropping a perpendicular from y onto the space spanned by the columns of X. The fitted values ŷ = Py are the "shadow" of y (P is the projection matrix). The residuals ε̂ = My are what's left (M = I − P is the residual maker). Both P and M are symmetric and idempotent (doing them twice changes nothing), and ŷ is perpendicular to ε̂.

Why OLS is a good choice: the Gauss–Markov theorem says that if the model is linear in β, X has full rank (no perfect collinearity), errors average zero given X (exogeneity), and errors have constant variance and are uncorrelated with each other, then OLS has the smallest variance of all linear unbiased estimators. Short name: BLUE (Best Linear Unbiased Estimator). Normal errors are not needed for BLUE; they're only needed for exact small-sample t and F tests.

"Linear" doesn't mean "straight"

Linear means linear in the β's. You can transform the x's and y however you like:

  • log(y) = β₀ + β₁x + β₂x² + ε is still a linear model (a curve!).
  • y = β₀ · x^β₁ · ε becomes linear after taking logs: log y = log β₀ + β₁ log x + log ε.

R²: how much variation the line explains

R² = 1 − RSS / TSS
RSS
residual sum of squares: total squared mistakes left over
TSS
total sum of squares: how spread out y is around its mean

For ordinary OLS with an intercept, measured on the data used to fit it, R² lies between 0 (line explains nothing) and 1 (perfect fit), and it equals the squared correlation between ŷ and y.

Careful: when R² can be negative

The 0-to-1 range is not a law of nature. Without an intercept, or when a model is judged on new data (out of sample), RSS can exceed TSS and the formula gives a negative R². That simply means the model predicts worse than the plain mean ȳ. Some software also reports a different "uncentred" R² for models without an intercept, so the number isn't comparable.

Trap

Very different datasets can have the same R² (Faraway shows four with R² = 0.65). Always plot your data. For explanation, a low R² is not automatically a problem.

Worked example

log(wage) = β₀ + β₁·education + β₂·age + ε, and say β̂₁ = 0.07.

Correct sentence: "For people of the same age, one more year of education is associated with about 7 % higher wages."

Note the words same age (holding others fixed) and associated with (not "causes"). Your lecturer stresses both.

Interaction termsdeeper
log(wage) = β₀ + β₁educ + β₂south + β₃south·educ + ε. Outside the South the education slope is β₁. In the South it is β₁ + β₃ and the intercept shifts by β₂. So β₃ answers "is the return to education different in the South?"

Inference: t-tests, F-tests, intervals deeper

If errors are normal, β̂ is normal too: β̂ ~ N(β, σ²(XᵀX)⁻¹). That lets us test things.

t = β̂ᵢ / se(β̂ᵢ) ~ tn−p
se(β̂ᵢ)
standard error: how much β̂ᵢ would jump around across samples
n − p
degrees of freedom: observations minus parameters

Tests H₀: βᵢ = 0. Big |t| means the estimate is many standard errors away from zero.

F-test compares a big model Ω with a smaller one ω that drops some variables: F = [(RSSω − RSSΩ)/q] / [RSSΩ/(n−p)], where q is the number of dropped variables. "Do these variables together add anything?"

Confidence interval: β̂ᵢ ± t · se(β̂ᵢ). The parameter is fixed. The interval is the random thing.

Predicting a new point x₀: the interval for the average y at x₀ uses √(x₀ᵀ(XᵀX)⁻¹x₀). The interval for one future y uses √(1 + x₀ᵀ(XᵀX)⁻¹x₀). The extra "1+" is the new person's own error ε₀, so prediction intervals are always wider.

t-test = regression, if you code it right. Regress y on an intercept and one dummy (1 = group B, 0 = group A). The intercept is group A's mean, the dummy's coefficient is the difference in means, and its ordinary t-statistic is exactly the pooled-variance (equal-variance) two-sample t-test. (Two dummies and an intercept would be perfectly collinear; two dummies without an intercept just give the two group means.)

If the two groups have different spreads, the matching test is Welch's t-test. The regression version is the same dummy regression with heteroskedasticity-robust standard errors (HC2 gives Welch's standard error exactly; the degrees of freedom differ slightly).

What can go wrong

1 · Omitted variable bias (the big one)

True model includes ability, but we can't measure it:

β₁(what we get) = β₁* + β₃* · γ₁
β₁*
true effect of education
β₃*
effect of ability on wage
γ₁
how ability moves with education

The bias disappears only if ability doesn't affect wages (β₃* = 0) or isn't related to education (γ₁ = 0). Otherwise your slope picks up part of ability's effect.

Related: Simpson's paradox. Adding one variable can flip the sign of another coefficient. So two models can give completely different β̂₁.

2 · Collinearity

When x's are strongly correlated with each other, OLS can't tell them apart. Estimates get high variance and become unstable.

  • Spot it: correlations near ±1; regressing xⱼ on the other x's gives Rⱼ² near 1; condition number √(λ₁/λp) ≥ 30.
  • Measure it: variance of β̂ⱼ is multiplied by 1/(1 − Rⱼ²), the variance inflation factor.

3 · Heteroskedasticity

"Hetero" = different, "skedastic" = spread. The errors are bigger for some x's than others (e.g. y = 1 + 3x + x·ε: bigger x, bigger noise). The usual standard-error formula assumed constant spread σ².

Heteroskedasticity does not bias β̂ (as long as errors still average zero given X). What breaks is the conventional standard errors, and with them t-tests and confidence intervals.

  • Fix A, weighted least squares: give noisy points less weight, wᵢ = 1/var(yᵢ). Example: if yᵢ is an average over nᵢ people, use wᵢ = nᵢ.
  • Fix B, robust standard errors (HC0–HC3): keep OLS β̂, fix only the standard errors. Angrist & Pischke prefer this one.
Explain: heteroskedasticity

The noise around the line is bigger in some places than in others.

Food spending against income: low-income households all spend similar amounts on food, while high-income households vary a lot (some eat out every day, some don't). The cloud of points fans out as income grows.

Var(εᵢ | xᵢ) = σᵢ² is not constant. If E[ε | X] = 0, OLS stays unbiased, but Var(β̂ | X) = (XᵀX)⁻¹XᵀΩX(XᵀX)⁻¹ ≠ σ²(XᵀX)⁻¹, so the usual SEs are wrong. HC estimators plug ε̂ᵢ² into Ω. OLS is no longer BLUE; GLS/WLS with the right weights is.

4 · Clustered errors

People in the same school or town share shocks. Cluster your standard errors when treatment is assigned at group level, or when you sampled groups first and people second.

  2. Turn on heteroskedasticity, then press "Repeat 500 samples". The average slope stays at the truth (no bias), but the usual SE understates the real spread, so its "95 %" CI covers the truth only around 90 % of the time. The robust SE is much closer (robust SEs are themselves slightly optimistic with only 50 points).
  3. Raise the ability correlation. The blue line gets steeper than the truth in every sample: omitted variable bias. Repeating samples doesn't fix it, and the CIs miss the truth almost every time.
  4. Add the outlier. One far-right point with a big residual drags the whole line. Points far from the mean of x have high leverage.

Choosing a model deeper

  • Occam's razor: among similar models, prefer the simpler one (especially for explanation). For prediction, a bigger model can be fine.
  • Automatic selection by p-values is risky. After many tests the p-values are no longer valid and results look better than reality. Freedman (1983): with p = 50 variables and n = 100, you find "patterns" in pure noise.
  • Information criteria = fit minus a penalty for complexity. AIC = −2·logL + 2p and BIC = −2·logL + p·log n, where p is the number of parameters. Because log n > 2 once n ≥ 8, BIC punishes extra parameters harder and prefers smaller models. Lower is better.
  • Note on the slides: one slide writes the BIC penalty as 2p·log n. That is not the standard definition; treat it as a typo or a non-standard scaling, and use p·log n unless your lecturer says otherwise. Model rankings between AIC and BIC can differ either way.
  • If models that fit equally well give very different answers, the honest conclusion may be that the data can't answer the question.

What p-values and CIs actually mean

Your lecturer spends several slides on this, so expect it in an exam.

All of these are wrong
  • "p = 0.08 means an 8 % chance that chance alone produced the result."
  • "p = 0.01 means the null hypothesis has a 1 % chance of being true."
  • "p ≤ 0.05 means the null is false."
  • "This 95 % CI has a 95 % chance of containing the true value."
  • "If two CIs overlap, the difference isn't significant."
Correct versions

p-value: If the model is right and the null hypothesis is true, then in repeated samples you'd see a test statistic at least this extreme about p·100 % of the time. It measures how compatible your data are with the model + null.

95 % CI: a recipe that, in repeated samples, produces intervals that cover the true value about 95 % of the time. Any single interval either covers it or doesn't.

Statistical ≠ practical significance. A tiny effect can be "significant" with lots of data. Always ask whether the size matters economically.

Explain: standard error

A standard error tells you how much your estimate would change if you collected a different sample of people.

Imagine surveying 100 students to estimate their average study time. If you repeatedly picked different groups of 100, their averages would differ a little each time. The standard error describes how much those averages typically vary.

The standard error is the estimated standard deviation of an estimator's sampling distribution. For an i.i.d. sample mean it is s/√n. For OLS, se(β̂ⱼ) = √[σ̂²(XᵀX)⁻¹]ⱼⱼ under constant variance, or the square root of the sandwich (XᵀX)⁻¹(Σ ε̂ᵢ² xᵢxᵢᵀ)(XᵀX)⁻¹ for robust SEs.

Explain: p-value

How surprising your result would be if there were really no effect, assuming your model is right. Small p = surprising.

A friend says a coin is fair. You flip it 20 times and get 16 heads. If the coin really were fair, a result at least that lopsided (16+ heads or 16+ tails) happens about 1.2 % of the time. So p ≈ 0.012: hard to square with "fair", but not impossible.

p = P(|T| ≥ |tobs| ; H₀ and the model), using T's null distribution (e.g. tn−p). If H₀ and the model hold, p is uniformly distributed on [0, 1]. It is not P(H₀ | data), and it says nothing about effect size.

Other bits from the slides deeper

  • Logistic regression: for 0/1 outcomes (got a job, passed a test). Models log(p/(1−p)), so predicted probabilities stay between 0 and 1.
  • Poisson regression: for counts (0, 1, 2…). Models log(mean).
  • GLMs are the family that includes normal, logistic and Poisson: a linear predictor η = Xβ plus a "link" that connects it to the mean.
  • PCA: squeeze many correlated x's into a few uncorrelated "components" that keep most of the variance.
  • Missing values: deletion, imputation, matching. First ask why they're missing.
  • Practical habits: always plot the data, ask how it was collected, never edit the raw file, comment your code.

OLS regression in five questions

The question to ask every timeWhy would my coefficient be biased?
  1. What problem are we solving?Describe how the average of Y changes with X, either to predict or to compare people who differ in X but are alike in the other regressors.
  2. How does the method solve it?Pick the line (or plane) that makes the sum of squared residuals as small as possible: β̂ = (XᵀX)⁻¹Xᵀy.
  3. What must hold?
    • Linear in the β's, no perfect collinearity.
    • Exogeneity, E[ε | X] = 0: nothing left in ε is related to X. Needed for unbiased (and causal) slopes.
    • Constant variance and independent errors: needed for the usual standard errors.
    • Normal errors: only for exact small-sample t and F tests.
  4. What happens when it fails?
    • Omitted variable or reverse causality: β̂ is biased, and more data doesn't help.
    • Heteroskedasticity or clustering: β̂ is fine, the usual SEs are wrong.
    • Collinearity: β̂ is unbiased but very noisy.
  5. How can we check?
    • Plot residuals against fitted values and each x.
    • See whether the coefficient moves when plausible confounders are added.
    • Use robust (or clustered) SEs by default.
    • Ask what is missing from the model, and in which direction it would push β̂.

Maximum likelihood

Maximum likelihood asks: which parameter value would make the data I actually saw most probable? That value is your estimate.

About 25 min in Full modeAbout 8 min in Gist mode

Quick reminders
Probability distribution
A rule saying how likely each possible value is (e.g. binomial for coin flips).
i.i.d.
Independent, identically distributed: separate draws from the same distribution.
Derivative
The slope of a curve. It's 0 at the top of a hill, which is how we find maximums.

If you remember only 3 things

  1. Likelihood = probability of your data, viewed as a function of the parameter. The data are fixed; you slide the parameter around.
  2. Take logs, take the derivative, set it to zero. Logs turn a product into a sum, which is much easier.
  3. A sharp peak means a precise estimate. The curvature at the top (Fisher information) gives you the standard error.

The coin example

You flip a coin 500 times and get 97 heads and 403 tails. Is it fair?

If p = 0.5, seeing exactly 97 heads has probability about 9.3 × 10⁻⁴⁶. Basically impossible. So which p fits best?

Worked example
  1. Probability of the data: L(p) = C · p⁹⁷ (1−p)⁴⁰³ (C is a constant that doesn't depend on p).
  2. Take logs: ℓ(p) = 97·log p + 403·log(1−p) + const.
  3. Derivative = 0: 97/p − 403/(1−p) = 0.
  4. Solve: p̂ = 97/500 = 0.194.

The MLE is just the share of heads. Most simple MLEs match your intuition like this.

See it: the likelihood explorer

The shaded band marks the p values within 1.92 log-points of the top: a likelihood-based 95 % interval. Keep the share of heads fixed and raise n: the hill gets sharper and the band and SE shrink. That sharpness is the Fisher information.

Explain: likelihood

How well a particular parameter value explains the data you actually saw.

You saw 15 heads in 50 flips. If p were 0.5, that result would be fairly unlikely. If p were 0.3, it would be as likely as it can be. The likelihood gives every candidate p a score; the MLE is the top scorer.

L(θ) = ∏ f(xᵢ | θ), read as a function of θ with the data fixed. It is not a probability distribution over θ (it needn't integrate to 1). θ̂ = argmax ℓ(θ); the observed information −ℓ″(θ̂) gives SE(θ̂) ≈ 1/√(−ℓ″(θ̂)).

The recipe

  1. Pick a distribution for your data with an unknown parameter θ: f(x | θ).
  2. Write the likelihood. With independent (i.i.d.) observations it's a product: L(θ) = f(X₁|θ) · f(X₂|θ) · … · f(Xₙ|θ). Independence is what lets you multiply.
  3. Take logs: ℓ(θ) = Σ log f(Xᵢ|θ). Same maximum, numerically more stable.
  4. Set the derivative (the score) to zero and solve. If there's no formula, a computer climbs the hill numerically.
Think of it like

A detective with fixed evidence (the data) trying out different suspects (parameter values). The best suspect is the one under whom this evidence is least surprising.

Waiting-time example (exponential)

100 waiting times between insurance claims. Model: exponential with mean λ, f(x|λ) = e^(−x/λ) / λ.

Worked example
  1. ℓ(λ) = −n·log λ − n·X̄/λ
  2. Score: −n/λ + n·X̄/λ² = 0
  3. λ̂ = X̄, the sample mean.

Challenger: why logistic regression needs ML

Each shuttle launch had 6 O-rings; some failed. We want the failure probability pᵢ as a function of temperature.

  • A straight line pᵢ = β₀ + β₁·temp can predict probabilities below 0 or above 1. Bad.
  • Fix: model the log-odds, log(pᵢ/(1−pᵢ)) = β₀ + β₁·tempᵢ. Any β gives a p between 0 and 1.
  • Randomness: failures yᵢ ~ Binomial(6, pᵢ). Now the model is fully described except for β₀, β₁.
  • Likelihood: multiply C(6,yᵢ)·pᵢ^yᵢ·(1−pᵢ)^(6−yᵢ) across launches, take logs, and let the computer find the β's that maximise it.

The vocabulary of the hill deeper

TermFormulaPlain meaning
ScoreSₙ(θ) = ∂ℓₙ/∂θSlope of the log-likelihood. Zero at the top.
Hessian∂²ℓₙ/∂θ∂θᵀSecond derivative: how curved the hill is. At a maximum it is negative (the hill curves down).

Why the MLE is approximately normal: a Taylor expansion of the score around θ₀ gives √n(θ̂ − θ₀) → N(0, H⁻¹JH⁻¹) = N(0, J⁻¹). So for large n, Var(θ̂) ≈ 1/(n·J). For the exponential: Var(λ̂) ≈ λ²/n, so SE ≈ λ̂/√n.

Why people love MLE

  • Consistent: θ̂ → true θ as n grows (needs i.i.d. data, identification and some regularity conditions).
  • Asymptotically normal: you can build t-tests and confidence intervals.
  • Asymptotically efficient: it hits the Cramér–Rao lower bound, the smallest variance any unbiased estimator can have: Var(θ̃) ≥ (nJ)⁻¹.
  • Invariant: if θ̂ is the MLE of θ, then h(θ̂) is the MLE of h(θ). Example: the MLE of p² is p̂².

Link back to lecture 1

If y = Xβ + ε with normal errors, the log-likelihood is a constant minus (1/2σ²)·Σ(yᵢ − xᵢβ)². Maximising it is the same as minimising the sum of squared residuals.

So OLS = MLE when errors are normal. (Small difference: MLE estimates σ² = ε̂ᵀε̂/n, dividing by n instead of n − p.)

Maximum likelihood in five questions

The question to ask every timeWhat distribution am I assuming for the data?
  1. What problem are we solving?Estimate the parameters of a model for the whole distribution of the data (coin flips, waiting times, 0/1 outcomes).
  2. How does the method solve it?Choose the θ that makes the observed data most probable: maximise ℓ(θ) = Σ log f(xᵢ | θ). The curvature at the top gives the SE.
  3. What must hold?
    • The assumed distribution is (close to) right.
    • Independent observations, so the likelihood is a product.
    • The parameter is identified and not on the edge of its range.
    • Large n for the normal approximation and SE ≈ 1/√information.
  4. What happens when it fails?
    • Wrong distribution: θ̂ targets a "pseudo-true" value and Hessian-based SEs are wrong (use the sandwich H⁻¹JH⁻¹).
    • Small n or a boundary: the normal approximation is poor.
  5. How can we check?
    • Compare fitted and observed distributions.
    • Compare the observed information with the outer product of scores (information matrix equality).
    • Try alternative distributions and report robust SEs.

The bootstrap

You only have one sample, but you want to know how much your estimate would change with a different sample. So you pretend your sample is the population and resample from it, many times.

About 20 min in Full modeAbout 7 min in Gist mode

Gist mode is on: deeper sections are hidden.

Quick reminders
Sampling distribution
How an estimate (like a mean) would be spread out over many different samples.
Standard error
The standard deviation of that sampling distribution.
Percentile
The value below which that % of numbers fall (2.5th percentile: 2.5 % are lower).
With replacement
After picking a value you put it back, so it can be picked again.

If you remember only 3 things

  1. Resample n observations from your data, with replacement. Some values appear twice, some not at all.
  2. Recompute your estimate on each resample, thousands of times. The spread of those estimates is your standard error. Their 2.5th and 97.5th percentiles give a 95 % CI.
  3. It needs few assumptions but can fail, e.g. when the parameter sits on the edge of what's allowed, or for the sample maximum.

The algorithm

  1. Draw a sample of size n from your data (the empirical distribution F̂ₙ), with replacement.
  2. Compute your statistic on it: T*.
  3. Repeat B times (say 1,000–10,000).
  4. Use the B values of T*: their standard deviation = SE, their percentiles = CI, their mean minus the original = bias estimate.
Think of it like

You can't go back and survey the country again. But your 1,000 respondents are a mini-version of the country. Drawing from them with replacement is like running the survey again in that mini-country.

Explain: bootstrap standard error

How much your estimate jumps around when you recompute it on reshuffled copies of your own data.

Your 9 claim times are a mini-population. Draw 9 of them with replacement, compute the mean, and do that 1,000 times. The spread of those 1,000 means mimics how the mean would vary if you could collect new samples.

SEboot = SD of T*₁, …, T*B, where each T* is computed on a sample from the empirical distribution F̂ₙ. It is consistent when Gₙ(·, F̂ₙ) → Gₙ(·, F₀): smooth statistics of i.i.d. data. B only controls Monte Carlo error.

The key logic: F̂ₙ is close to the true F, so how estimates vary when sampling from F̂ₙ is close to how they vary when sampling from F. More resamples B only make the simulation more accurate; they don't add real information.

When to reach for it

  • Moderately small samples where "large n" formulas are shaky (e.g. n = 30–50 with skewed data), provided the sample still represents the population reasonably well.
  • Complicated estimator with no known formula for its variance (e.g. the output of a numerical optimisation).
  • Formula depends on unknowns. The sample median's variance is 1/(4n·f(m)²), which needs the unknown density f at the median.
  • Dubious assumptions, e.g. stock returns with fat tails, where normality is wrong.
Careful: the bootstrap is not a small-sample cure

It resamples the data you have; it can't create information that isn't there. With very few observations (like the 9 in the demo above), the sample is a crude stand-in for the population, the bootstrap distribution is lumpy, and 95 % intervals often cover the truth less than 95 % of the time. Its guarantees are themselves large-sample results. A small sample stays a small sample.

The stamp example deeper

Question: were stamps printed on one type of paper or several? If one, the distribution of thickness should have one mode (one peak).

  • H₀: number of modes = 1. Find ĥ₁ = 0.0068, the smallest smoothing level at which the estimated density has one peak.
  • Draw bootstrap samples from a smoothed version of the data that has exactly one mode (a smooth bootstrap, adjusted to keep the right variance).
  • For each, compute ĥ₁*. Count how often ĥ₁* ≥ ĥ₁: that share is the achieved significance level.
  • With B = 5,000 it came out at 0.0002 < 5 %, so reject "one paper type".

Lesson: choosing a clever test statistic and null hypothesis improves the power of the test.

When the bootstrap fails

  • Parameter on the boundary. E.g. X ~ N(μ, 1) but μ is only allowed to be ≥ 0, and the true μ = 0 (Andrews, 2000).
  • Sample maximum. If data are uniform on [0, θ], the bootstrap max equals the sample max with probability 1 − (1 − 1/n)ⁿ → 1 − 1/e ≈ 63 %. The real sampling distribution has no such spike. So the bootstrap gets it wrong.
  • The paradox: we want the bootstrap in complicated situations, but those are exactly where it's hardest to prove it works.

Fix: subsampling. Draw smaller samples (size m < n) without replacement. Works more generally, but is less efficient when the normal bootstrap works, and you have to choose m.

The theory words deeper

  • Gₙ(τ, F₀): true distribution (CDF) of your test statistic. Unknown because F₀ is unknown.
  • Bootstrap estimate: Gₙ(τ, F̂ₙ). Plug in the data's distribution instead of the true one.
  • Pivotal: the statistic's distribution doesn't depend on F at all. Asymptotically pivotal: true in large samples (e.g. a t-statistic).
  • Bootstrap consistency: Gₙ(·, F̂ₙ) → Gₙ(·, F₀) as n → ∞. Beran & Ducharme's sufficient conditions: F̂ₙ is a good estimate of F₀, the limit distribution is continuous in τ, and it changes smoothly with F.

The bootstrap in five questions

The question to ask every timeDoes resampling reproduce the relevant sampling uncertainty?
  1. What problem are we solving?Get a standard error or confidence interval for an estimator that has no simple formula, or whose formula needs unknowns.
  2. How does the method solve it?Treat the sample as the population: draw n observations with replacement, recompute the statistic, repeat B times, and use the spread.
  3. What must hold?
    • The sample represents the population well (n not tiny).
    • Observations are independent (or the resampling copies the dependence, e.g. block bootstrap).
    • The statistic depends smoothly on the data (not a maximum, not a boundary parameter).
  4. What happens when it fails?
    • Tiny n: intervals cover the truth less often than they claim.
    • Maximum or boundary: the bootstrap distribution is wrong (spike at the sample maximum).
    • Dependent data resampled as if independent: SEs too small.
  5. How can we check?
    • Is the statistic smooth? Is the data independent?
    • Compare with an analytic SE where one exists.
    • Try subsampling (m < n, without replacement) when in doubt.

Intro to causality

To know if something causes an outcome, you need to compare people who are alike in every way except the treatment. Randomness is what makes that comparison fair.

Worked example: randomising this class of six

The six effects are −2, −2, +2, −4, −1, −2. They sum to −9, so the true average effect (ATE) is −9 / 6 = −1.5.

  1. A coin puts Adam, Boris and Ema in the treated group. We see their Y(1): (4 + 5 + 3)/3 = 4.0.
  2. We see the others' Y(0): Cyril, Diana, Filip = (6 + 7 + 3)/3 = 5.33.
  3. Estimate = 4.0 − 5.33 = −1.33. A different coin (Cyril, Diana, Filip treated) gives 4.0 − 5.67 = −1.67.

Why a naive comparison misleads: selection bias

Without randomisation, comparing the treated with the untreated mixes two things:

E[Y|D=1] − E[Y|D=0] = ATT + (E[Y(0)|D=1] − E[Y(0)|D=0])

Step by step: subtract and add E[Y(0)|D=1]. The first pair is the ATT; the second pair compares the two groups' untreated outcomes. Randomisation makes that second pair zero.

Worked example (from the R lab below)

People who join a gym are already healthier than people who don't. Comparing their health a year later mixes the gym's effect with who chose to join.

What to control for: confounders, mediators, colliders

"Add more controls" is not always safer. It depends on where a variable sits in the causal picture (a DAG, directed acyclic graph: arrows mean "causes").

VariableExampleControl for it?
Confounder (causes D and Y)Ability, when D = education, Y = wageYes. Leaving it out causes omitted variable bias.
Mediator (on the path D → M → Y)Occupation, if education raises wages partly by getting you a better jobNo, if you want the total effect. Controlling for it removes part of the effect you're measuring.

Collider in action

Among admitted students only, high test scores and high motivation look negatively related: anyone admitted with low scores must have had high motivation, and vice versa. In the whole population there may be no link at all. Studying only the admitted (selecting on a collider) invents the correlation.

Randomisation inference deeper

In an experiment you can get a p-value without any normal approximation. Take the sharp null: treatment has no effect on anyone, so Y(1) = Y(0) for every person and all outcomes are known.

  1. Compute your observed difference in means.
  2. Re-run the random assignment many times on paper (all splits, or a few thousand), keeping outcomes fixed, and recompute the difference each time.
  3. The p-value is the share of re-assignments with a difference at least as extreme as the one you observed.

The uncertainty here comes from which units were assigned to treatment, not from sampling from a population. It's exact in small experiments and is the logic behind permutation tests (Faraway §3.3). Same "simulate the world under H₀" idea as the bootstrap, with a different source of randomness.

The problem: we usually can't randomise

Questions where a proper experiment is impossible or unethical:

  • Do veterans earn less because of the war?
  • Does education increase wages?
  • How does the minimum wage affect unemployment?
  • Does class size affect learning? Does alcohol cause car crashes?

Option 1: compare similar people, Y(1), Y(0) ⫫ D | X ("random once we control for X"). Works only if you've measured everything that matters.

Option 2: find a source of randomness, a "quasi-experiment".

The quasi-experiment idea

Some Z (a lottery, a birth date, the weather) pushes the treatment D, and touches Y only through D:

Z → D → Y, and no arrow Z → Y

Then: β̂ = effect(Z→Y) / effect(Z→D) = Cov(Y,Z)/Cov(D,Z). With a 0/1 Z: (E[Y|Z=1] − E[Y|Z=0]) / (E[D|Z=1] − E[D|Z=0]). This is exactly the IV estimator of lecture 5.

  • Generalisation: does the result apply beyond this sample?

  • Qualitative support for causality: the effect is strong, consistent, specific, stable over time, monotone (more dose, more effect), plausible, and confirmed by experiments.

The lecture's conclusion: results are based on models, so be critical. But some questions matter so much that an imperfect answer beats none.

Randomised experiments in five questions

The question to ask every timeWould the two groups have had the same outcomes without the treatment?
  1. What problem are we solving?Measure the effect of D on Y when the people who get D might differ from those who don't.
  2. How does the method solve it?Assign D at random, then compare average outcomes. Randomisation makes D independent of the potential outcomes, so selection bias is zero on average.
  3. What must hold?
    • Random assignment (independence).
    • No spillovers between units (SUTVA).
    • People take the treatment they are assigned (or you analyse by assignment).
    • No differential drop-out.
  4. What happens when it fails?
    • Selection into treatment: the difference in means mixes the effect with who chose it.
    • Non-compliance: comparing by assignment gives the ITT; use IV for the effect of treatment itself.
    • Attrition that differs by group: biased comparison.
  5. How can we check?
    • Balance table on pre-treatment characteristics.
    • Compliance and attrition rates by group.
    • Randomisation inference for small experiments.

The problem: endogeneity

D is endogenous (correlated with the error) when there is:

  • an omitted variable U,
  • reverse causality (Y also affects D),
  • or measurement error in D.

Then the OLS condition E[D·η] = 0 fails and OLS is biased.

Think of it like

Z is a clean knob that turns D up and down without touching the noise in Y. The first stage finds how much D moved because of the knob. The second stage asks how much Y moved along with that clean movement.

The three (four) conditions

ConditionPlain meaningTestable?
RelevanceZ actually moves D: Cov(Z, D) ≠ 0Yes: look at the first stage
IndependenceZ is as good as random, unrelated to UNo (argue it)
ExclusionZ affects Y only through DNo (argue it)
Monotonicity (for LATE)Z pushes everyone in the same direction. No "defiers".No

Independence + exclusion together = validity: E[Z·η] = 0.

The formulas

δ̂_OLS = Cov(D, Y) / Var(D) δ̂_IV = Cov(Z, Y) / Cov(Z, D)

Same shape. OLS uses D's own variation (contaminated). IV uses only the variation that comes through Z.

δ̂_Wald = (ȲZ=1 − ȲZ=0) / (D̄Z=1 − D̄Z=0)
top
reduced form: how much Y differs between Z groups
bottom
first stage: how much D differs between Z groups

The version for a 0/1 instrument (like a lottery). This is the one to use in exam calculations.

Where the formulas come from: method of momentsdeeper
Write down conditions that hold at the true value, then solve their sample versions. For a mean: E[Y − μ] = 0 ⇒ μ̂ = Ȳ. For OLS: residuals average zero and are orthogonal to D, giving Cov(D,Y)/Var(D). For IV: keep "residuals average zero", but replace the second condition with residuals orthogonal to Z, Σ Zᵢ(Yᵢ − α − δDᵢ) = 0. Demean and solve: δ̂ = Cov(Z,Y)/Cov(Z,D). We weight by Z because E[Zη] = 0 is believable, while E[Dη] = 0 is exactly what fails.

Two-stage least squares (2SLS)

  1. First stage: regress D on Z (and controls X). Save the fitted values D̂.
  2. Second stage: regress Y on D̂ (and the same X, but not Z).

The slope on D̂ equals the IV ratio exactly.

Trap

If you run the two stages by hand, δ̂ is right but the standard errors are wrong: the second-stage residual uses D̂ instead of the real D. Always use an IV command (ivreg in R, ivregress 2sls in Stata).

Controlsdeeper
If X affects both Z and Y, Z is only valid given X, so X goes in both stages. Equivalent trick (Frisch–Waugh–Lovell): regress Y, D and Z each on X, keep the residuals, then apply the simple formula Cov(Z⊥, Y⊥)/Cov(Z⊥, D⊥). "Controlling for X" = removing X from everything, then using what's left.

Weak instruments

Rewrite: δ̂_IV − δ = Cov(Z, η) / Cov(Z, D). If Z barely moves D, the bottom is near zero, so tiny noise on top gets blown up. The estimate becomes erratic, and conventional standard errors and t-tests stop being trustworthy.

Which way does it go wrong? In the textbook setting (one endogenous D, conventional 2SLS, Z truly valid), the finite-sample distribution of 2SLS tends to be centred towards the OLS estimate, because with little clean variation the estimate is dominated by the same contaminated variation that biases OLS. This is a common pattern, not a universal law: with many instruments it gets worse, with just-identified IV the estimator may not even have a finite mean, and if Z is also slightly invalid, a weak first stage magnifies that bias in any direction.

Old rule of thumb: first-stage F-statistic of at least 10. Newer work (Lee, McCrary, Moreira & Porter 2022) shows the usual ±1.96 t-test needs F around 104 to be reliable. With a weaker first stage, use weak-instrument-robust inference such as Anderson–Rubin confidence intervals.

See it: strong, weak and invalid instruments

Each press runs 500 imaginary studies with 200 people. A hidden U raises both D and Y, so OLS is biased. The true effect of D is 0.5. Make the instrument weaker, or let it affect Y directly (breaking exclusion), and watch the IV estimates.

Things to try
  1. Strong instrument (0.5 or more): IV estimates centre on 0.5; OLS sits far to the right.
  2. Slide strength down to about 0.1: the median F drops below 10, IV estimates spread out widely and their median drifts towards OLS, so fewer studies land near the truth. The usual 95 % CIs become so wide they say little.
  3. Set strength to 1 (F around 100), then add a direct effect of 0.2: IV now centres on about 0.7, not 0.5, despite the big F. F checks relevance, never validity. Then weaken the instrument: the bias grows, because the violation is divided by a smaller first stage.

LATE: who does IV tell us about?

In real experiments people don't always follow their assignment (imperfect compliance). Comparing by assignment gives the ITT (intention-to-treat): the effect of being offered treatment.

Explain: LATE

The effect for the people whose treatment was changed by the instrument.

In the KIPP lottery, some families would send their child to KIPP whatever happened (always-takers) and some never would (never-takers). The lottery only changes what the "compliers" do, so it can only tell us about them.

Under relevance, independence, exclusion and monotonicity, (E[Y | Z=1] − E[Y | Z=0]) / (E[D | Z=1] − E[D | Z=0]) = E[Y(1) − Y(0) | D(1) > D(0)] (Imbens & Angrist 1994). Different instruments have different compliers, so different LATEs.

Always- and never-takers do the same thing whatever Z is, so they add nothing to the reduced form. All of it comes from compliers. So reduced form ÷ first stage = average effect for compliers, the LATE.

Worked example: KIPP charter schools (lottery)
  1. Attendance: 78.7 % of winners and 4.6 % of losers attended KIPP. First stage φ = 0.787 − 0.046 = 0.741.
  2. Math scores (in standard deviations): winners −0.003, losers −0.358. Reduced form ρ = 0.355. This is the ITT.
  3. LATE = ρ/φ = 0.355 / 0.741 = 0.479.
  4. Shares: compliers 0.741, always-takers 0.046 (losers who attended anyway), never-takers 1 − 0.787 = 0.213.

Attending KIPP raised math scores by about 0.48 SD for children who attended only because they won the lottery.

Two words for non-compliance: treatment migration (controls get treated anyway) and treatment dilution (assigned people don't take it).

Case study: kids and mothers' work deeper

Angrist & Evans (1998). Does a third child reduce mothers' labour supply?

  • Instrument: first two kids are the same sex. Parents like a mix, so they're more likely to try for a third. Sex is as good as random.
  • First stage: 43.2 % of same-sex families had another child vs 37.2 % of mixed: +6.0 points.
  • Result (worked for pay): OLS −0.176, 2SLS −0.120. A third child lowers compliers' chance of working by 12 points. OLS overstated it.
  • Compliers are only about 6 % of families. Says nothing about always-takers. A different instrument (e.g. twins) has different compliers, so a different LATE.
  • Husbands: effect ≈ 0.

Case study: institutions and growth deeper

Acemoglu, Johnson & Robinson (2001). Do good institutions make countries rich?

  • Instrument: settler mortality. Where Europeans died a lot, they set up extractive states. Where they could live, they built settler institutions. Institutions persisted.
  • Story: mortality → settlements → early institutions → today's institutions → today's income.

More instruments than you need deeper

With 2 instruments for 1 treatment, each gives its own estimate. If both are valid, those should be similar. The overidentification test (Sargan / J-test) checks this: J ~ χ²q with q = (number of instruments) − (number of endogenous variables). Caveat: it can only check instruments against each other, never prove they're valid.

Other classic instruments: Vietnam draft lottery, distance to college (Card), distance to hospital (heart attacks), rainfall (civil conflict), weather (fish demand).

  3. What must hold?
    • Relevance: Z moves D.
    • Independence: Z is as good as random.
    • Exclusion: Z affects Y only through D.
    • Monotonicity (for LATE): no defiers.
  4. What happens when it fails?
    • Weak first stage: erratic estimates and unreliable usual SEs; in the textbook case they drift towards OLS.
    • Invalid Z: biased, and a weak first stage magnifies the bias.
    • Effects differ between people: you get a LATE for compliers, not an ATE.
  5. How can we check?
    • First-stage F (relevance; ≥ 10 classic, ~104 for plain t-tests).
    • Balance of covariates across Z (partial check of independence).
    • Argue exclusion; try placebo outcomes Z shouldn't affect.
    • With several instruments, an overidentification test.

Regression discontinuity

Rules often switch a policy on at a sharp cut-off. If nothing else changes at the cut-off and people can't precisely place themselves on one side, then the jump in the outcome right at the cut-off is the effect.

Quick reminders
Cut-off (threshold)
The exact value where a rule switches, e.g. "born on or after 1 July 1990".
Density
How many observations sit at each value of a variable (a smoothed histogram).
Bias–variance trade-off
Using more data lowers noise (variance) but can add systematic error (bias), and the other way round.
Placebo test
Run the analysis where there should be no effect. If you find one, something's off.

If you remember only 3 things

  1. Treatment depends on a running variable X crossing a cut-off c. Compare outcomes just below and just above c.
  2. Key assumption: nothing else jumps at c, and people can't precisely sort themselves to one side. Check with a density test, covariate balance and placebo cut-offs.
  3. Use local linear regression near c, not high-order polynomials over all the data. The effect is local: it's the effect for people at the cut-off.

On this page

The picture is the method

Imbens & Lemieux: if the basic plot shows no jump, fancy regressions are unlikely to find a credible one. Always start with the plot.

Sharp RD

Dᵢ = 1{Xᵢ ≥ c}
Xᵢ
running variable (or forcing variable): score, age, date of birth
c
cut-off
1{…}
equals 1 if true, 0 if false

Knowing X tells you D exactly. That's what "sharp" means.

Identifying assumption, continuity: the average potential outcomes E[Y(0)|X] and E[Y(1)|X] change smoothly through c. Without treatment, there would be no jump. So:

τ = limx↓c E[Y|X=x] − limx↑c E[Y|X=x] = E[Y(1) − Y(0) | X = c]

Average just above minus average just below = average effect at the cut-off. Away from c the effect could be different, and the data can't tell you by how much.

Think of it like

A student who scored 79 and one who scored 80 may be almost the same student. If only the 80 gets a scholarship, comparing them can be close to a coin flip.

Careful: closeness is not the assumption, continuity is

Being near the cut-off does not automatically make people comparable. The comparison is valid only if (1) the average potential outcomes change smoothly through c, so nothing else jumps at c (no other policy, benefit or label uses the same cut-off), and (2) people can't precisely control which side they land on. Lee (2008) shows that under (2), RD behaves like a local randomised experiment. Both are assumptions to argue and check (density test, covariate balance, placebo cut-offs), never facts that follow from proximity.

Validity checklist
  1. Density of X: no jump at c.
  2. Covariate balance: things decided before treatment (age, past earnings) don't jump at c.
  3. Placebo cut-offs: no jumps at fake cut-offs.
  4. Donut RD: estimate doesn't change much without the closest points.
  5. Bandwidth sensitivity: estimate stable across reasonable bandwidths.

Estimating it

Yᵢ = α + τDᵢ + β(Xᵢ − c) + γDᵢ(Xᵢ − c) + εᵢ
τ
the jump at the cut-off: your effect
β
slope on the left side
β + γ
slope on the right side (the interaction lets slopes differ)
Xᵢ − c
centred running variable, so τ is measured exactly at c
  • Global polynomials (fit the whole range with x, x², x³…): avoid high orders. Far-away points get big, erratic weight. In the slide's simulation (true τ = 1), estimates ranged from 0.55 to 2.2 depending on the polynomial order (Gelman & Imbens 2019).
  • Local linear (recommended): use only points with |X − c| ≤ h (the bandwidth), fit a line on each side, and weight closer points more (triangular kernel).

See it: the bandwidth simulator

Six hundred simulated people. Treatment switches on at X = 0 and the true jump there is 0.4. The relationship curves, and differently on each side, so wide windows can mislead. The shaded window is the bandwidth; blue points are the ones used.

Narrow the bandwidth to 0.08. Why did your estimate become less precise?

Fewer points fall inside the window, so each side's line is fitted on little data and its intercept at the cut-off is noisy. A wider window uses more data (smaller SE) but compares people further from the cut-off, where the curve bends, so the straight lines start to miss the true jump (bias). Try h = 1: the SE is small but the estimate is pushed well away from 0.4. That is the bias–variance trade-off that rdrobust's bandwidth selector balances.

Move "where you test" away from 0. What should you find, and why is this useful?

No jump (truth = 0): nothing changes at a fake cut-off. This is a placebo test. Finding jumps at fake cut-offs would suggest your method is picking up curvature or noise rather than a treatment effect. (For placebo cut-offs the simulator uses only data on the same side of the real cut-off.)

Explain: bandwidth

How far from the cut-off you look.

Comparing students who scored 79 with those who scored 80 compares very similar people, but there are few of them. Comparing 70–79 with 80–89 gives far more people, but they are less alike. The bandwidth is the size of that window.

Local polynomial fit with kernel weights K((Xᵢ − c)/h). For local linear, bias is of order h² and variance of order 1/(nh), so the MSE-optimal h shrinks like n−1/5. At that h, conventional CIs under-cover; robust bias-corrected CIs (Calonico, Cattaneo & Titiunik 2014) fix this.

Bandwidth and inference deeper

  • Small h: less bias (only very similar people) but more variance (fewer points).
  • Large h: more data, less variance, but more bias.
  • MSE = bias² + variance. Data-driven selectors pick the h that minimises it (in the slides' simulation h* ≈ 0.78). Report results at 0.5×h and 1.5×h too.
  • Kernel matters much less than bandwidth. Triangular is standard; uniform = plain OLS inside the window.
  • Robust bias-corrected CIs (Calonico, Cattaneo & Titiunik 2014). At the MSE-optimal h, ordinary CIs are too narrow. Software: rdrobust.
  • Report τ̂, its SE, h, the kernel and the polynomial order. Cluster where treatment is assigned.

Fuzzy RD = IV at the cut-off

Sometimes crossing c only raises the chance of treatment. E.g. students scoring below 80 are eligible for free tutoring, but some don't go and some above 80 find a way in.

τ_FRD = (jump in Y at c) / (jump in P(D = 1) at c)

The Wald ratio from lecture 5: reduced form ÷ first stage. Eligibility Z = 1{X < 80} is the instrument. You get a LATE for compliers at the cut-off. Estimate with 2SLS in the same window.

Assumptions: relevance (eligibility shifts take-up, testable), exclusion (crossing 80 matters only through tutoring; it fails if being labelled "below 80" discourages students), monotonicity.

Case study: Austrian parental leave

Lalive & Zweimüller (2009). From 1 July 1990, parental leave was extended from 1 to 2 years. Running variable = child's date of birth. Compare June 1990 mothers (control) with July 1990 mothers (treated).

Results
  • Year-2 leave taken: +9.3 months. The treatment really changed.
  • Another child within 36 months: +4.5 percentage points (13–16 % above the mean of 0.345).
  • Returned to work within 36 months: −10.9 points. After 10 years: −3 points.
  • Earnings in years 0–3: about −€2.7 per day. Years 4–10: no significant difference.

Regression discontinuity in five questions

The question to ask every timeCould something other than the treatment change at the cut-off?
  1. What problem are we solving?Treatment is assigned by a rule at a cut-off of a score, age or date, and treated people differ from untreated ones overall.
  2. How does the method solve it?Compare outcomes just above and just below the cut-off, with a local linear fit on each side within a bandwidth.
  3. What must hold?
    • Continuity: average potential outcomes change smoothly through c (nothing else jumps there).
    • No precise sorting: people can't choose their side.
    • The local linear fit is a good approximation inside the bandwidth.
  4. What happens when it fails?
    • Another policy at the same cut-off: the jump mixes both.
    • Manipulation: people just above differ from those just below.
    • Too wide a bandwidth or high-order polynomials: biased; too narrow: noisy.
  5. How can we check?
    • Density test (rddensity).
    • Covariates shouldn't jump at c.
    • Placebo cut-offs and donut RD.
    • Estimates across bandwidths; robust bias-corrected CIs (rdrobust).

No. RD identifies the effect at X = c. Extending it further needs extra assumptions.

Difference-in-differences

Don't just compare before and after: other things change over time too. Compare the treated group's change with a control group's change. The difference between the two changes is the effect.

About 40 min in Full modeAbout 12 min in Gist mode

Gist mode is on: deeper sections are hidden.

Quick reminders
Panel data
The same units (people, stores, states) observed at several points in time.
Fixed effect
A separate intercept for each unit (or each period) that soaks up everything constant about it.
Counterfactual
What would have happened without the treatment. Never observed; it has to be estimated.
Percentage point (pp)
Plain difference between two percentages: 40 % → 45 % is +5 pp (but +12.5 %).

If you remember only 3 things

  1. DiD = (treated after − treated before) − (control after − control before).
  2. Key assumption: parallel trends. Without treatment, both groups would have changed by the same amount. Levels can differ; trends can't. It can't be tested directly; pre-trends in an event study are a partial check.
  3. With staggered timing and changing effects, plain two-way fixed effects (TWFE) can be badly wrong, because it uses already-treated units as controls. Use Callaway & Sant'Anna-style estimators.

The 2 × 2 setup and its assumptions

DiD = (μ₁,₁ − μ₁,₀) − (μ₀,₁ − μ₀,₀)
μg,t
average outcome for group g (1 = treated, 0 = control) in period t (1 = after, 0 = before)
Yᵢₜ = α + βGᵢ + γPostₜ + δ(Gᵢ × Postₜ) + εᵢₜ
β
baseline gap between groups
γ
common time change
δ
the DiD effect (extra change for the treated after)

The same number as the four-means formula, just written as a regression.

The target is the ATT: average effect on the treated group after treatment. It's identified under three assumptions:

  • Consistency / SUTVA: observed outcome = potential outcome under the treatment received. Treatment is well defined, and there are no spillovers onto the control group.
  • No anticipation: the treated don't react before treatment starts (e.g. to an announced policy).
  • Parallel trends: E[Y₁(0) − Y₀(0) | treated] = E[Y₁(0) − Y₀(0) | control]. The only assumption about the unseen counterfactual.

The derivation in three stepsdeeper
(1) Add and subtract the treated group's "before" outcome, so ATT = (actual change of treated) − (untreated change of treated, unknown). (2) Parallel trends replaces that unknown change with the control group's change. (3) Consistency + no anticipation turn every potential-outcome term into an observed mean. Result: ATT = (μ₁,₁ − μ₁,₀) − (μ₀,₁ − μ₀,₀).

Explain: parallel trends

Without the policy, both groups would have changed by the same amount.

Two cities' café sales both grow about 3 % a year. City A introduces a sugar tax, and its sales then grow only 1 % while city B's still grow 3 %. That suggests the tax cost about 2 %, but only if A would otherwise have kept growing 3 % too.

E[Ypost(0) − Ypre(0) | treated] = E[Ypost(0) − Ypre(0) | control]. It concerns an unobserved post-period counterfactual, so it can't be tested directly, and it depends on the scale (parallel in levels ≠ parallel in logs).

Trap

Parallel trends does not require equal levels. Lambeth and S&V had wildly different levels (62 vs 565). Only the changes need to match without treatment.

Adding covariates deeper

Conditional parallel trends: trends are parallel within groups with the same X. Compute DiD in each X-cell, then average using the treated group's mix.

Slide example

Cell X=0: DiD = 1. Cell X=1: DiD = 2. Treated are 20 % / 80 % in these cells, so ATT = 0.2·1 + 0.8·2 = 1.8. Ignoring X gives 3.0, a bias of 1.2, because most treated units are in the fast-trend cell.

In a regression, covariates must be allowed to shift the trend: add Xᵢ × Postₜ. Adding Xᵢ alone does nothing (DiD removes level differences anyway). Better tools: regression adjustment, inverse probability weighting, or doubly robust DiD (Sant'Anna & Zhao 2020).

Event studies: checking pre-trends

Replace the single "treated × after" dummy with one dummy per period relative to treatment, k = t − (adoption time). Leave out k = −1 as the reference.

  • Leads (k < 0): should be near zero. If not, trends weren't parallel before.
  • Lags (k ≥ 0): how the effect evolves. The slides' fracture example shows income dropping by over €500/month at month 2 and slowly recovering. One average number would hide that.
Trap: flat leads are evidence, not proof
  • Parallel trends is a claim about the post-treatment counterfactual, which is never observed. Leads only show the groups moved together before.
  • Pre-trend tests often have low power: with noisy data, a real pre-trend big enough to bias your estimate can easily be "insignificant" (Roth 2022).
  • Picking a specification because it passes the pre-trend test distorts the final estimate and its confidence interval.
  • Better practice: show the event-study plot, report how big a violation would have to be to change your conclusion (sensitivity analysis, Rambachan & Roth 2023), and argue why trends would stay parallel.

Staggered adoption: why TWFE breaks

Many groups, treated at different times. The usual regression is two-way fixed effects: Yᵢₜ = αᵢ + λₜ + β·Dᵢₜ + uᵢₜ (unit FE + time FE).

Goodman-Bacon (2021): β_TWFE is a weighted average of every possible 2×2 DiD in the data:

  1. early-treated vs never-treated ✓
  2. late-treated vs never-treated ✓
  3. early vs late (late still untreated) ✓
  4. late vs early, using the already-treated early group as control ✗

If effects grow over time, the early group keeps changing after treatment. Using it as a "control" subtracts that growth. The estimate can even flip sign.

The fix: Callaway & Sant'Anna

Rule: never use already-treated units as controls. For each cohort g (first treated in period g) and each later period t, compute a clean 2×2 DiD called ATT(g, t):

  • Treated change: cohort g from s = g − 1 (last pre-period) to t.
  • Control change: units not yet treated at t (or never treated), over the same s → t.

Standard errors

Outcomes of the same unit are correlated over time, so ordinary SEs are far too small (Bertrand, Duflo & Mullainathan 2004). Cluster at the level where treatment is assigned (e.g. state). With very few treated clusters (one state!), even clustered SEs are unreliable.

Case study: minimum wage (Card & Krueger 1994)

  • April 1992: New Jersey raised the minimum wage from $4.25 to $5.05. Pennsylvania didn't.
  • 410 fast-food restaurants surveyed before (Feb–Mar) and after (Nov–Dec).
  • Result: NJ employment rose by 2.33 full-time-equivalent workers per store relative to PA. Theory predicted a fall.
  • Alternative: use each NJ store's "wage gap" (how much it had to raise wages). Coefficient 15.65 × average gap 0.11 ≈ +1.7 FTE.
  • Prices of a meal rose about 3.3 % relative to PA. More full-time workers (+7.3 pp). No clear changes in opening hours.
  • Debate: Neumark & Wascher (2000) used payroll data and found negative effects. Card & Krueger (2000) used administrative data and found none. The original paper showed no parallel-trends evidence, and one treated vs one control state limits inference.

Difference-in-differences in five questions

The question to ask every timeWhy would the groups have followed parallel trends without treatment?
  1. What problem are we solving?A policy reaches some groups and not others. A before–after comparison mixes the effect with everything else that changed over time.
  2. How does the method solve it?Subtract the control group's change from the treated group's change. With staggered timing, build clean 2 × 2 comparisons (ATT(g, t)).
  3. What must hold?
    • Parallel trends: same change without treatment (levels may differ).
    • No anticipation before the start date.
    • No spillovers onto the control group.
    • Staggered timing with TWFE: effects must not change over time (otherwise use Callaway & Sant'Anna).
  4. What happens when it fails?
    • Non-parallel trends: the bias equals the gap in trends.
    • Anticipation: changes appear before the policy.
    • TWFE with staggered, growing effects: wrong, sometimes wrong sign.
  5. How can we check?
    • Event study: leads near zero (evidence, not proof).
    • Sensitivity to plausible violations (Rambachan & Roth).
    • Compare TWFE with clean estimators.
    • Cluster SEs where treatment is assigned.

  geom_pointrange(aes(ymin = est - 1.96 * se, ymax = est + 1.96 * se)) +

# (c) Staggered adoption: cohort A treated from t = 3, B from t = 6, N never; effects grow
st <- expand.grid(unit = 1:150, t = 1:8)
st$g <- c(3, 6, Inf)[ceiling(st$unit / 50)]
st$D <- as.numeric(st$t >= st$g)

st$y <- rnorm(150)[st$unit] + 0.5 * st$t + st$effect + rnorm(nrow(st), 0, 0.5)
twfe <- coef(lm(y ~ factor(unit) + factor(t) + D, data = st))["D"]

att_gt <- function(gg, tt) {                          # clean 2x2: cohort gg vs not-yet/never treated at tt
  base <- gg - 1
  ctrl <- st$g > tt
  chg <- function(sel) mean(st$y[sel & st$t == tt]) - mean(st$y[sel & st$t == base])
  chg(st$g == gg) - chg(ctrl)
}
cells <- do.call(rbind, lapply(c(3, 6), function(gg)
  data.frame(g = gg, t = gg:8, att = sapply(gg:8, function(tt) att_gt(gg, tt)))))
true_avg <- mean(st$effect[st$D == 1])

round(c(TWFE = unname(twfe), clean_average = mean(cells$att), true_average = true_avg), 2)

Review: quick recall

Answer in your head first, then tap to check. Come back to these a few days later.

Treated: 50 → 70. Control: 40 → 50. DiD?

(70 − 50) − (50 − 40) = 20 − 10 = 10.

Do treated and control need the same level of Y before the policy?

No. Only the same trend without treatment (parallel trends).

In an event study, what should the leads look like, and what do they prove?

Close to zero. They make parallel trends more plausible but can't prove it: the assumption is about the post-period, and pre-trend tests often lack the power to detect a harmful trend.

Which TWFE comparison causes trouble, and why?

Late-treated vs already-treated early units. If the early group's effect keeps changing, that change gets subtracted.

At what level should you cluster standard errors?

At the level where treatment is assigned (e.g. state for a state law).

Which causal method?

  1. Can you randomise? Run an experiment and compare means. Done.
  2. Is there something random that pushes the treatment (lottery, weather, birth timing) but doesn't touch Y directly? Use IV.
  3. Does a rule switch treatment on at a cut-off of some score, age or date? Use RDD (fuzzy RDD if the cut-off only changes the odds).
  4. Did a policy hit some groups and not others, with data before and after? Use DiD (Callaway & Sant'Anna if timing is staggered).
  5. None of these? Regression with controls, but be honest that it shows association unless you've controlled for everything that matters.
